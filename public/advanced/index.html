Config fields

  • instructions - assistant behavior/context for every reply.
  • title - label shown on the chat tab and widget title.
  • starterMessage - short line above the starter suggestions.
  • starterSuggestions - up to three quick prompts shown before the first message.
  • theme - light or dark; omit for host auto-detect.
  • position - bottom-right, bottom-left, top-right, top-left.
  • accentColor - main widget accent hex color.
  • tagline, quickLinks, and info - optional content sections.
  • siteID and variant - optional identifiers/labels.

Routes
